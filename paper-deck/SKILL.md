# Image-generated research deck

Resolve the audience, presentation objective, approximate length, and language from the request. Establish a narrative that connects the research question, method, evidence, and conclusion. Check the paper's actual results before using them in a slide.

This workflow is for slides whose main artwork is produced by an available raster image-generation tool. If the user requests editable native slides instead, use the host presentation workflow. If the requested image-generation tool is unavailable, state the limitation; do not pass screenshots or programmatic drawings off as generated images.

Plan the purpose and information hierarchy of each slide. Keep labels, typography, notation, color, and composition consistent across the deck. Preserve supplied figures and numerical evidence rather than regenerating them as invented illustrations. Use the requested aspect ratio and export formats.

Choose generation and assembly steps based on available tools. Retain enough source information to revise generated slides. When adding editable text over image artwork, disclose which parts remain rasterized; do not promise full editability for a flattened image.

Reuse choices already specified or approved. Ask only about material ambiguity, and do not expand the slide count without a task-based reason. A single slide request does not require building a complete deck.

Inspect each image for legibility and scientific fidelity, then inspect the assembled presentation for cropping, ordering, and missing content. Provide the requested deck and any requested editable sources or PDF. Distinguish rendering checks from verification of scientific claims.
