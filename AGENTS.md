# Personal skills maintenance

This repository is the versioned authority for Eric's personal skill customizations. CC Switch manages installation, source registration, and client exposure.

- Edit and validate the repository first. When publication is authorized, commit and push the intended paths, then use CC Switch's repository update flow and verify the installed content against the pushed revision.
- Do not treat edits to `~/.cc-switch/skills` or client skill directories as a completed change. Do not replace the shared client-root links or bypass CC Switch with a second installation tree.
- Preserve registered directory identities when updating existing skills. A skill's display name may differ from its directory for compatibility; document that mapping.
- Keep third-party skills on their upstream source unless maintaining an explicitly attributed customization here. Never publish restricted upstream bundles or private runtime state. Preserve the licenses and notices of redistributed material.
- Keep skill discovery narrow. Put conditional procedures in references, retain evidence and artifact-validation requirements, and avoid mandatory workflow steps that exceed the user's request.
- Validate frontmatter and referenced resources. Test behavior in isolated examples when the change warrants it; distinguish static review from executed behavior and measured performance.
