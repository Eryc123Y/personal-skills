# Evidence-backed investigation

Define the question, relevant period, and intended decision from the request. Ask only when uncertainty about scope would materially change the work. Match coverage and output length to the question; neither a source quota nor a fixed number of search rounds establishes completeness.

Identify authoritative sources and plausible opposing evidence. Read the underlying sources before relying on them, record dates where freshness matters, and distinguish reported findings, your synthesis, and unresolved hypotheses. Do not treat a search snippet, planned experiment, or proxy metric as validation of a broader claim.

Use independent bounded retrieval or preliminary review when authorized and useful. A lightweight agent can collect sources; the coordinating agent checks the evidence and owns the final conclusions. Avoid duplicating the same searches across agents.

Explain the answer, supporting evidence, limitations, and implications in the order useful to the reader. Cite each material factual claim to a source that supports it. State conflicts and missing evidence rather than inventing precision or consensus.

Return the requested format. An inline answer does not require a saved report, HTML, PDF, or background follow-up. For an artifact, use the selected output location and appropriate host authoring tools; verify references and the actual exported result. Report any verification that could not be completed.
